# مشروع اختبار A/B: قياس أثر التذكير الآلي بمواعيد الخدمات

## 1. سؤال البحث والفرضية
- **السؤال:** هل إضافة ميزة التذكير الآلي بمواعيد الخدمات عبر الرسائل النصية تزيد من نسبة التزام العملاء بالحضور؟
- **الفرضية الصفرية ($H_0$):** لا يوجد فرق معنوي في معدل الحضور بين النسختين.
- **الفرضية البديلة ($H_1$):** الرسائل التذكيرية تزيد من معدل الحضور بشكل دال إحصائياً.

## 2. تصميم التجربة
- **وحدة التخصيص:** `user_id`
- **المجموعة A (Control):** بدون تذكير تلقائي.
- **المجموعة B (Treatment):** تذكير آلي قبل الموعد بـ 24 ساعة.
- **نسبة التوزيع:** 50% لكل مجموعة.

## 3. التحليل والنتائج
- تم التحقق من سلامة التوزيع (SRM Check) باستخدام اختبار كاي تربيع ولم يظهر أي خلل إحصائي دال.
- أظهرت النتائج ارتفاعاً ملحوظاً في نسبة الحضور للمجموعة التجريبية (B).
